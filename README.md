# 🃏 ຊາເຈົ້າ (Cát Tê) - P2P

越南/老挝传统卡牌游戏，支持2-6人P2P联机对战。

## 两种模式

### 🌐 联网模式（默认）
- 使用PeerJS云服务器
- 所有设备需要联网
- 打开 https://guocheng1378.github.io/catte-game-p2p/

### 📶 局域网模式（无需联网）
1. 在一台电脑上启动信令服务器：
   ```
   npm install express peer
   node server.js
   ```
2. 所有玩家连接同一WiFi
3. 游戏页面点击左上角「📶 LAN」
4. 输入服务器IP（如 192.168.1.100:9000）
5. 创建/加入房间开始游戏

## 玩法
- 2-6人轮流出牌
- 每人6张牌，6轮
- 第1-4轮(Tứ): 牌型越大越强
- 第5-6轮(Trưng): 谁先出完谁赢
- Tùng/Chết Tùng 淘汰机制
